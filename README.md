# Aura — Creative Talent Studio

A minimal, warm editorial-style agency website that connects teams with creative and technical talent — either direction.

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JS](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

> **Live:** https://kakashiairdrops.github.io/agency-website/

## Features

- Animated hero with rotating wordmark & mouse parallax
- Selected work showcase
- Services with color-shift hover states
- Process, testimonials & FAQ accordion
- **Two signup paths** — "Find talent" vs "Get hired" (skills field appears for creators)
- Newsletter signup, custom cursor, scroll progress & scroll-spy nav

## Tech

Plain HTML / CSS / JavaScript — no build step, no dependencies.

## Run locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

Or just double-click `index.html`.

## Structure

```
├── index.html   # markup & content
├── style.css    # design system (warm editorial theme)
└── script.js    # interactions
```
