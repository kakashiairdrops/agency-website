# Aura Studio — Creative Talent Website

A minimal, warm editorial-style agency website connecting teams with creative and technical talent.

## Sections
- Hero with animated typography & parallax
- Selected Work
- Services
- Process
- Voices (testimonials)
- FAQ
- Join (Hire / Get hired with modal)
- Newsletter

## Tech
Plain HTML / CSS / JavaScript. No build step — open `index.html` or serve statically.

## Local
```bash
python3 -m http.server 8000
# open http://localhost:8000
```
